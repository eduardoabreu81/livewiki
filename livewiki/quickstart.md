# Quickstart

livewiki is an agent-first documentation tool: it indexes a repo's code
symbols (via tree-sitter) into a SQLite index, and lets a wiki under
`livewiki/` anchor markdown prose to those symbols. `livewiki verify`
catches any anchor pointing at a symbol that doesn't exist — the
anti-hallucination guarantee this whole tool exists for.

This repository (livewiki documenting itself) has **92 files** indexed
and **304 symbols** extracted across 3 packages.

- **[cli.md](cli.md)** — `@livewiki/cli`: the `livewiki` command-line

## How it fits

The `.playwright-mcp/` directory holds timestamped YAML accessibility snapshots produced by the Playwright MCP browser harness against a running livewiki build. Each snapshot captures the full DOM tree of a livewiki page at the moment of capture, including the left-hand navigation sidebar, group headings, link labels, URL targets, and the rendered document body. The directory sits alongside `.claude`, `.github`, and `docs/` in the repository root and is generated by tooling outside of livewiki's own source tree. ## How snapshots are structured

Every snapshot follows the same shape: a top-level `generic` node wrapping a `navigation` node and a `main` node. The `navigation` node contains a header link (the `repo — livewiki docs` or `livewiki — livewiki docs` link targeting `../../index.html` or `index.html`), a search box and theme toggle, and a sidebar of groups (`Quickstart`, `Implementation reference`, `Diagrams`, `Wiki indexes`, `Activity`). Each sidebar group exposes its link list or appears as a closed `group` with no expanded children when collapsed. The `main` node carries the page `<h1>` and the rendered document body, which is either a list of paragraph symbols (for structure and modules pages), a Mermaid code block (for class-diagram pages), or prose with link lists (for the Quickstart page).

## What this page does not cover

The snapshots themselves are YAML accessibility trees, not live source code, so this page does not document function or method signatures, runtime behavior, or API contracts of livewiki itself. The sidebar link inventory and the structure-tree listing visible inside each snapshot reflect only what the browser captured at that timestamp and may differ from the current state of the livewiki build.
